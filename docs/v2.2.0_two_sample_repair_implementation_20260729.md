# annotate-spatial-transcriptomics v2.2.0 双样本故障修复实施记录

> 日期：2026-07-29
> 范围：D05521A1、D05521C3 暴露的通用运行和逐大类复核缺陷。
> 当前状态：代码、schema、文档和本地回归测试已完成；尚未重放样本，尚未推送 GitHub。

## 已关闭的 P0 缺陷

1. 逐大类全样本复核的每个 broad 现在必须绑定同一 membership 上的四项证据：当前成员精度、全 query 召回、raw-count/全转录组分子身份、整张切片空间合理性。
2. 删除自由文本关键词证明路径。decision 必须绑定 controller 生成的 evidence packet SHA；有未解决 precision/recall challenger 时，`retain_current_cell_type` 直接失败。
3. exact cell-ID patch 只能作用于 evidence packet 中已登记的 current-member question 或 outside-recall question，不能利用 whole-query scope 任意改标签。
4. 任一 membership patch 都改变全局 semantic signature，因此下一轮会重新打开全部 broad；不能复制上一轮 retain 结论形成空 round。
5. catalog patch 新增 source/delta/result membership transform ledger；post-catalog completeness 沿该链追溯 post-merge component、Atlas/local/ROI 和 catalog 来源。
6. incident registry validation 绑定当前物理 SHA、semantic SHA 和 row count；registry 追加后旧 validation 失效。

## 已关闭的 P1 缺陷

1. 新增 exact-runtime preflight：实际 Python/R 路径与版本、Python 编译/import、R 包、JSON/TSV reader 和输入 hash 在阶段运行前检查。
2. `run_seurat_cohort_recluster.R` 与 SCE wrapper 不再使用 `chdir=TRUE`；控制器传递绝对路径。
3. 大 cohort 默认且强制单 resolution worker；新增资源计划，≥20,000 observations 建议 64 CPU，并在已声明内存不足时于读取/复制大对象前阻断。
4. partition cache 使用规范化 cell-ID set semantic hash 判断 membership 等价，保留物理 SHA 作审计。
5. Atlas target + held-out disjoint union 增加 required/optional schema 检查，缺失 `fine_anchor_eligible` 等可选字段时补确定性默认值。
6. 非空 Atlas discrepancy queue 返回可恢复的 `REVIEW_REQUIRED`，不登记为软件崩溃；恢复时仍需绑定同一 queue/decision。
7. `发情后期2` 等受控阶段别名可被规范化，但 context 仍只有 evaluation permission，不能增加身份分数。
8. 羊卵巢 broad evidence packet 绑定完整空间定位、Oocyte canonical 和 follicle-ROI endpoint；Oocyte ordinary sparse-marker question 只有在 exact canonical membership 已通过时才可被替代。

## 固定术语

用户可见阶段名称固定为：

1. Atlas 后暂定注释
2. 未解析成员局部复核
3. 最终完整性初审
4. 羊卵巢三项复核
5. 逐大类全样本复核
6. 精确成员修订
7. 修订后重新复核全部大类
8. 最终完整性与羊卵巢三项复核
9. pending_user_review 报告

“目录复核”“目录审阅决策”“来源组复核”“强制重放”不再作为用户可见替代阶段。

## 测试结果

- 修改过的 Python 脚本全部通过 `py_compile`。
- 修改过的 R entrypoint/export/recluster 脚本全部通过 R parser。
- Skill 结构通过 `skill-creator` quick validation。
- 重点 runtime、Atlas、contract、resource、incident、context 和 broad-review 回归：78/78 PASS。
- 全测试发现 214 项：207 PASS、4 SKIP；剩余 3 项均因当前登录节点 base Python 缺 numpy/pandas 或 ST_seurat 缺 scipy 而未执行，不是新的断言失败。正式数值环境仍需重跑这 3 项。
