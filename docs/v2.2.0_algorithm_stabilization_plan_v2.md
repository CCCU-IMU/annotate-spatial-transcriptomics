## 一、架构纠偏与失败产物隔离

- 终止 A08/A09“第一轮全组织逐 cellbin 分类—空间拆分—remainder 闭环—直接生成 release membership”路线，不再继续 A10。
- A08/A09 产物完整保留并登记为 `failed_diagnostic`，仅用于分析过度召回、低置信和运行效率问题。
- A08/A09 的 `release_membership`、标签、阈值结论和 semantic hash 不得进入正式注释、历史标签、Atlas、测试预期或 D05522A3 盲回归输入。
- contract 增加 artifact role；只有 `runtime_input` 和明确声明的 `external_reference` 可参与注释，`failed_diagnostic` 只能用于统计诊断。
- 现有未提交代码和产物不做 destructive reset，选择性重构并保留失败证据。

## 二、文献审查与算法定位

- 不建立固定“羊卵巢标准大类表”；候选目录保持开放。
- 羊卵巢、跨物种及人/鼠卵巢文献分别作为候选谱系、解剖结构、竞争假设和 Atlas challenger 的先验。
- 文献 marker 不充当分类器。正式身份联合多基因 marker family、DEG/anti-DEG、pseudobulk、相邻分辨率稳定性、空间形态和技术替代解释。
- 第一轮未出现的 Epithelial、Endothelial、Pericyte/mural、Smooth muscle、Theca、Luteal、Glial/Schwann-like 或其他谱系可在第二轮重建。
- D05522A3 v2.1.0 仅在新结果冻结后用于外部验收，不作为运行时 Atlas、候选白名单或标签来源。

## 三、唯一标准注释控制器

`run_lineage_controller.py` 是唯一正式入口，分为：

1. `whole_tissue_partition`
2. `cluster_cohort_recluster`
3. `local_mixed_subcluster_split`
4. `merge_and_freeze_broad`
5. `atlas_and_completeness_review`
6. `materialize_final_release`

控制器必须满足：

- annotation contract 绑定控制器、依赖脚本、候选目录、profile、输入快照、seed 和 SHA256。
- 第一轮没有 release authority，不能生成正式 broad/fine/QC membership。
- 正式 broad membership 只能由 `merge_and_freeze_broad` 生成；fine 只能在 broad freeze 后物化。
- 项目自编 scorer、subset writer 或 remainder closer 只能产生 experimental 产物。
- 历史标签在第二轮候选评分、分辨率选择和 membership 冻结前保持不可见。
- 固定排序、固定 seed 和分辨率级派生 seed，保证并行执行的确定性。

## 四、标准执行流程

### 4.1 输入冻结

- 冻结 `full_object`、`analysis_set`、`excluded_initial_qc` 和项目原始 count assay。
- cohort 必须读取项目自身非 SCT assay 的 raw counts，优先 `RNA`、其次 `Spatial`；禁止对 SCT corrected counts 再运行 SCTransform。
- 禁止跨项目复用表达对象，外部 Atlas 除外。
- 客观零 count 或损坏条目可为 `excluded_initial_qc`；生物学未决成员在第二轮完成前不得称为 QC。

### 4.2 第一轮全组织聚类

- 第一轮只构建第二轮 cohort，不产生正式注释。
- SCT+BANKSY whole-tissue grid 默认 `0.2,0.4,0.6,0.8`。
- 选择保留主要空间结构、相邻分辨率稳定且无明显技术碎裂的分辨率；不要求分离所有谱系。
- 每个初始 cluster 只记录 `provisional_broad`、`mixed` 或 `unknown`，以及候选程序、竞争程序和缺失谱系 `watch`。
- provisional broad 只属于 cluster-level cohort 计划，不写入正式 cell ledger，不冻结成员身份。
- observation direct/local signal 只能描述程序、混合和 watch，不得驱动正式逐 cellbin 写回。
- 第一轮禁止全对象逐 cellbin 正式分类、candidate-local 拆分、exact remainder、fine 写回、residual-QC 完成门、release authority 和 release membership。
- 第一轮唯一成员产物是 `whole_tissue_cohort_plan.tsv`；所有 `analysis_set` 成员必须且只能进入一个初始 cluster。

### 4.3 第二轮 cluster cohort 重聚类

每个第一轮 cluster 默认形成一个独立 cohort，包括看起来已经纯化的 cluster：

`raw counts → SCT v2/glmGamPoi → PCA → query-only SNN → Leiden grid`

- 羊卵巢默认 grid 为 `0.1,0.2,0.3,0.4,0.6`。
- PCs 和 k 根据 cohort 大小、谱复杂度和稳定性自适应，不复用 whole-tissue BANKSY 图参数。
- 每个分辨率计算 membership、DEG、pseudobulk、空间形态和完整候选目录证据。
- 选择时比较完整 grid；稳定性使用最近的低/高相邻分辨率，边缘候选使用两个最近分辨率，不强制 selected 后还有两个更高分辨率。
- 优先身份程序分离、主要解剖结构、避免状态/深度/纯 ECM 碎裂、相邻稳定；指标相近时选择较低复杂度。
- 第二轮首先稳定 broad，而不是追求亚型数量。若较高分辨率产生大量 marker 不明显的小亚簇或 `unresolved_biological`，而相邻较低分辨率能恢复连贯 broad 且不掩盖已验证的少数谱系，则判为过度切分并选择较低分辨率。
- 无法建立有效图的极小 cohort 记录 `underpowered_not_evaluable`，进入最终 unresolved/Atlas 路径，不静默继承 provisional broad。
- 第二轮 scorer 在 provisional broad 不可见时扫描每个 Leiden subcluster 的完整开放目录。评分冻结后才读取 provisional broad，用于区分 `parent_return`、`cross_lineage_return`、`missing_broad_reconstruction`、`fine_candidate`、`state_annotation`、`unmodeled_lineage_candidate` 和 `unresolved_biological`。
- fine candidate 只作为 parent-bound proposal；正式 fine membership 在 broad freeze 后生成。

### 4.4 二级 subcluster 判定

- 主要注释单位是第二轮 Leiden subcluster。
- 高纯度 subcluster 在多基因身份、DEG/pseudobulk、无独立竞争谱系、空间形态和相邻稳定性共同支持时可整体返回 broad。
- 其中低 RNA、缺少直接 marker 但无 hard contradiction 的稀疏 cellbin 继承 broad，不因 dropout 自动进入 QC。
- 只有独立 child discriminator 足够时才释放 fine；亚型证据不足但 broad 背景明确时保留 parent broad-only。若出现不同于父簇的完整谱系程序，则跨谱系回归对应 broad，fine 仍可为空。
- 基因按当前 query 非零表达第 95 百分位缩放；family signal 取最强两个可用基因平均；direct/local 默认 `0.35/0.65`。
- 单个 anti-marker 或局部 anti 只降分；hard contradiction 要求直接、多基因且跨独立 anti-family。
- Aggregate winner 不能否决其他候选；generic ECM、ACTA2/TAGLN 或共同 parent 程序不能独立证明 specific lineage。

### 4.5 局部 observation-level 拆解

- 当一个二级 subcluster 同时含两个或以上独立身份核心，或一个 specific identity 嵌在 generic parent 中时，启动一次有界的局部可分离性检查。少数谱系可能被多数背景稀释，因此整亚簇 DEG 不是启动检查的硬前提。
- 每个候选独立形成 identity-core seed 和 candidate-local 空间组件；同一 subcluster 可提出多个候选子集。
- 只有逐细胞 discriminator、candidate-local DEG/pseudobulk、空间组件或相邻分辨率证明成员可分时才正式拆分写回；若信号共表达于同一批成员且没有可验证分区，则保留支持的 parent broad，并把替代程序留作 `watch`。
- 重叠成员以标准化证据、pairwise discriminator 和 anti-program 消歧；无法消歧者留在共同 parent 或 `unresolved_biological`，不得按候选顺序分配。
- Specific lineage 先于 generic Stromal remainder。
- `0.70 support / 0.30 competitor margin / ≤0.05 contradiction` 只验证已形成的候选子集，不作为逐 cellbin 入选门槛。
- exact remainder 只在该局部 subcluster 内运行，最多再提取一次新子集。
- 未进入候选子集不等于 QC；remainder 重新评估 parent、其他候选和 unresolved 状态。

### 4.6 全组织合并与 broad freeze

1. 合并 whole-subcluster return 和局部 supported subset。
2. 验证 membership 互斥、无重复并精确覆盖 `analysis_set`。
3. 对冲突成员重比来源证据；不能消歧者进入 `unresolved_biological`。
4. 冻结正式 broad membership。
5. 将 fine proposal 限定到冻结的正确 broad parent 内。
6. state annotation 使用独立列，不替代 broad/fine identity。

正式 broad 只能追溯至 second-round whole-subcluster、second-round supported local subset、second-round local remainder parent、post-merge unresolved Atlas rescue，或 Atlas 后仅针对 `unresolved_biological` 的严格种子空间组件复核；最后一种来源必须保存候选组件、重叠消歧与解剖 parent-override 审计，并且不得修改已冻结 broad。第一轮 provisional broad 不能成为正式来源。

### 4.7 Atlas 与最终完整性复核

- broad freeze 后运行一次全细胞 broad Atlas mapping。
- 未获得 broad 且为中高置信、非 OOD、ontology/profile 兼容者可回归 broad。
- 已定义 broad 与 Atlas 一致者关闭；大类冲突或 coherent OOD 触发一次完整来源 subcluster/cohort 复核。
- Atlas 不得静默覆盖现有 broad，不得直接生成 fine；同批次标签和 D05522A3 v2.1.0 不能作为 Atlas。
- Atlas 后只对仍未决成员执行一次 bounded component review：直接多家族 identity core 形成严格种子，同谱系连贯低 RNA 成员可在原二级亚簇空间图内继承，specific lineage 先于 generic remainder；目录声明的解剖上下文可把 lineage-of-origin 程序返回阶段定义的 broad parent，但不能使用全对象逐 cellbin 分类或为了达到 QC 门而放宽证据。
- 随后执行 residual QC、常见/缺失谱系、已注释 broad 的表达与空间、大簇内嵌谱系、unmodeled lineage 及 broad×fine 完整审计。
- `QC <10% 且 <50,000` 只在最终完成门执行；超过阈值时返回具体第二轮 cohort 或 post-merge unresolved 复核。

## 七、测试体系

### 7.1 固定小型集成 fixture

1. Granulosa-rich：高纯度继承、低 RNA tail、无基质弥散。
2. Stromal/Smooth muscle/Endothelial/Pericyte：多方拆分，内皮、周细胞和成熟平滑肌独立竞争，剩余基质归 Stromal。
3. 稀有 Oocyte：canonical cluster 全成员召回及污染/邻近细胞隔离。
4. 低比例 Epithelial：3%–5% 稳定程序在第二轮重建且不整簇扩张。
5. Unmodeled program：跨分辨率、空间连贯、非 stress/cell-cycle/纯 ECM，记录但不自动命名。

fixture 直接来自允许的原始输入，不读取 A08/A09 membership 或 D05522A3 v2.1.0 标签。

### 7.2 架构测试

- 第一轮不能生成 formal broad/fine/QC membership。
- provisional 字段不能进入第二轮 scorer。
- 每个 initial cluster 恰好进入一个第二轮 cohort。
- cohort SCT 必须来自非 SCT raw-count assay。
- 每个二级 subcluster 扫描完整候选目录。
- 第一轮未出现谱系可形成 `missing_broad_reconstruction`。
- observation-level 拆解只能在 mixed-subcluster trigger 后运行。
- 未进入 subset 的成员不能自动进入 QC。
- local exact remainder 不得读取全组织 membership。
- fine proposal 在 broad freeze 前不能正式写回。
- Atlas、residual-QC 和 completeness validator 在 merge 前调用必须失败。
- `failed_diagnostic` 不能成为 runtime input。
- 同输入、contract、seed 的分区、membership 和 semantic hash 完全一致。

### 7.3 参数稳健性

- 比较相邻 resolution、PCs ±5、k ±20%。
- 占比 ≥1% 的主要 broad 全部保留，不因扰动新增/删除占比 ≥1% 的 broad。
- broad census Spearman ≥0.95；主要 broad 空间 Dice ≥0.80。
- 主要 fine 保持相同 parent 和核心程序；稀有谱系按程序和空间单独审核。

## 八、D05522A3 独立盲回归

- fixture 通过后，从固定 SCT+BANKSY 原始输入创建独立项目。
- 不读取 v2.1.0 标签、repair membership、A08/A09 或同批 Atlas。
- 完整运行两次验证技术确定性，再运行参数扰动版本。
- 新结果冻结后才加载 v2.1.0 作外部比较。
- 验收要求：主要 broad 与空间结构等价；Granulosa 不弥散；Smooth muscle、Endothelial 与 Pericyte/mural 正确分离；Epithelial 不过召回也不漏失；Oocyte 遵循 canonical-cluster 规则；missing broad 可在第二轮重建；每个 broad 有多基因、DEG/pseudobulk 和空间证据；QC 同时低于 10% 和 50,000。
