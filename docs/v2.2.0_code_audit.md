# v2.2.0 代码审计与实施映射

本表记录已批准架构如何映射到代码。它不是发布声明；指定样本盲回归和用户验收完成前，`v2.2.0` 仅表示已同步至 `main` 的开发目标，不创建稳定 tag。

| 架构要求 | 权威实现 | 验证方向 |
|---|---|---|
| 第一轮只建 cohort | `build_whole_tissue_cohort_plan.py`、`run_lineage_controller.py whole_tissue_partition` | controller 内部计算一次完整 grid 证据，再将 selected resolution 物化为只含 cluster-level 证据的 view；不二次读取全对象或输出 observation scores；64-CPU 作业的 worker 上限为 64，实际并行仍按独立分辨率/候选数自适应；禁止 formal broad/fine/QC/release 字段；精确覆盖 analysis set |
| 第一轮与第二轮分辨率职责分离 | `build_resolution_grid_evidence.py`、`select_lineage_resolution.py` | whole-tissue 绑定 `whole_tissue_cohort_partition`；cohort 绑定 `cohort_identity_resolution`；二级选择先保证 broad 可解释性，`unresolved` 惩罚高于可局部解决的 mixed；marker-poor 小亚簇增多时比较相邻较低分辨率 |
| 每 initial cluster 一个 cohort | `build_whole_tissue_cohort_plan.py`、`validate_cohort_plan_binding` | cohort ID、cluster、provisional record 和 membership SHA256 精确一一对应 |
| 从项目 raw counts 重建图 | `run_seurat_cohort_recluster_impl.R`、raw-count ancestry manifest | 非 SCT assay；项目/样本/analysis hash 一致 |
| provisional 对 scorer 不可见 | `adjudicate_second_round_subclusters.py`、`validate_cohort_outcome.py` | score freeze 后才读取 provisional；任一家族或纯邻域连贯不能建立身份，候选 seed 必须绑定声明的 identity-core 家族且由群体内至少两个家族交叉支持 |
| 二级 subcluster 全目录扫描 | `run_observation_lineage_scoring.R`、`adjudicate_second_round_subclusters.py` | 完整 candidate × subcluster 覆盖 |
| missing broad 重建 | `adjudicate_second_round_subclusters.py` | broad/fine candidate 可回归 release broad parent；specific winner 必须是独立身份程序，generic Stromal 只作 remainder；无独立竞争者的 identity-dominant 高纯度亚簇允许整体继承 |
| 仅局部 observation 拆分 | `adjudicate_second_round_subclusters.py`、`derive_candidate_local_subsets.R` | aggregate contradiction 或被多数背景稀释的整亚簇 DEG 不得遮蔽 mixed-subcluster 候选；两个 specific identity 或一个 specific identity 加 generic remainder 触发有界可分离性检查；只有局部表达/空间组件通过才拆分写回；fine challenger 继承 broad writeback strategy，Epithelial component-only 不能反向扩张整簇；Oocyte canonical component 使用候选特异复核 |
| exact local remainder | `close_exact_remainders.py` | 不读取 source 外 membership；最后一次提取只重验已生成的 residual candidate-local component，不运行 remainder 全对象逐 bin 分类；已确认的跨谱系 blocker 不被 aggregate contradiction 二次遮蔽，state-only 不阻断 broad parent；不自动 QC |
| broad 仅 merge 冻结 | `merge_and_freeze_broad_membership.py` | analysis set 互斥、无遗漏、semantic hash 稳定 |
| fine parent lock | `materialize_parent_locked_fine_proposals.py` | broad freeze 后且 parent 匹配；无独立 child discriminator 时保持 broad-only，不得转成 unresolved 或伪造 fine |
| state 不扩张混合簇 | `adjudicate_second_round_subclusters.py`、`materialize_final_release_v2_2.py` | 仅正确 parent 的高纯度二级 subcluster 可写独立 state 列 |
| 极小 cohort | `materialize_underpowered_cohort` | `<3` observations 记录 not-evaluable；不继承 provisional、不提前称为 QC，可进入 calibrated Atlas rescue |
| Atlas post-merge only | `route_global_atlas_v2.py`、`apply_post_merge_atlas_routing.py` | 只救回 unlabeled；不覆盖 defined broad；不写 fine |
| 完整性与 unmodeled | `audit_post_merge_completeness.py`、`discover_unmodeled_lineages.py` | present/zero-census/full-catalog/unmodeled 审计；先排除 stress/state/纯 ECM，并用 scorer 冻结的候选家族命中数排除已知多家族程序，避免把 Immune、Granulosa、Theca 等误报为未知谱系 |
| typed final QC | `materialize_final_release_v2_2.py` | 仅最终转换 unresolved；10%/50,000 双阈值 |
| semantic repair 写回 | `apply_cell_id_membership_patch.py`、`write_frozen_annotations_to_seurat.R` | proposal 只能按唯一 `cell_id` 连接，恢复 base 顺序并证明非 proposal 成员未改变；禁止行序赋值 |
| Oocyte 零普查 challenger | `screen_rare_cell_programs.R`、`screen_spatial_foci.py`、`materialize_oocyte_cluster_membership.py` | 常规二级扫描为零但完整 analysis set 多模块 starting gate 非零时运行一次 label-blind query-only cohort；通过簇整体返回，仅 typed hard exclusion 可移除 |
| Theca/Luteal 边界 | sheep-ovary profile、candidate catalog | Theca 分子优先且 anatomy 仅事后挑战；Luteal 同时要求 steroidogenic core、corpus-luteum identity、阶段与实性结构 |
| 确定性与参数稳健性 | `evaluate_annotation_robustness.py` | exact repeat；Spearman/Dice/major-class invariants |
| 失败产物隔离 | contract artifact roles、项目 failed-diagnostic registry | A08/A09 与失败的 B04 集成产物不能成为 runtime/reference/fixture truth |
| 端到端来源链 | `validate_lineage_controller_release.py` | first plan→cohort/local→merge carry→Atlas→fine/state→final membership 全部重验路径、SHA 和 analysis-set 覆盖 |

## 明确退役的运行路径

- 第一轮 `release_authority.json` 与 `release_membership.tsv.gz`。
- 第一轮 formal broad/fine/QC writeback。
- 第一轮全对象 candidate-local subset 与 exact remainder closure。
- 按 initial broad 合并默认 cohort。
- “selected 加两个更高分辨率”的固定要求。
- 第一轮 residual-QC 比例门及返回全对象逐 bin 调阈值。
- A10 全对象调阈值运行。

## 保留但降权为兼容/迁移的组件

旧版 broad-class cohort、targeted cohort、direct return、initial broad ledger 和 frozen-QC Atlas 语义可继续读取旧项目，但新建 v2.2 项目不能以这些兼容字段建立正式 membership。完成验证必须根据 annotation contract 的架构版本选择 staged v2.2 路径。
