# v2.2.0 sheep-ovary vascular taxonomy refactor audit

Status: implemented and validated in the local working tree; not committed, pushed or tagged. No biological sample job was submitted.

## Final release taxonomy

The legacy `Vascular-associated` umbrella is forbidden as a runtime release label. The three competing broad identities are:

- `Endothelial`
- `Pericyte/mural`
- `Smooth muscle`

`Lymphatic endothelial` is an optional high-confidence fine identity whose internal parent is `Endothelial`. The single public annotation is `final_cell_type`: a release-grade fine identity replaces its parent broad; otherwise the broad is shown; terminal unresolved members are `QC/Unknown`.

The open sheep-ovary broad catalog otherwise retains `Oocyte`, `Granulosa`, `Theca`, `Luteal`, `Stromal/mesenchymal`, `Immune`, `Epithelial/mesothelial`, `Glial/Schwann-like` and other current-query-supported open lineages. This is a candidate audit surface, not a required per-sample label list.

## Identity programs

### Endothelial

- identity backbone: `PECAM1, CDH5, VWF, CLDN5, ESAM`
- independent angiovascular support: `KDR, FLT1, EMCN, EGFL7, RAMP2, PLVAP, KLF2, FLI1` plus available profile genes
- branch-like vascular morphology is supporting evidence only
- one endothelial marker or vascular location cannot release the identity

### Pericyte/mural

- identity backbone: `RGS5, PDGFRB, CSPG4, NOTCH3, MCAM, RERGL, ABCC9, KCNJ8, COX4I2`
- independent mural/contractile support: `DES, ACTA2, TAGLN, MYL9`
- the identity backbone, not shared contractility, determines the lineage

### Smooth muscle

- mature nonvascular contractile core: `MYH11, CNN1, ACTG2, SMTN, LMOD1`
- structural support: `TAGLN, ACTA2, MYL9, MYL6, DES, TPM2, FHL1`
- `ACTA2/TAGLN/MYL9` without the mature core cannot release Smooth muscle
- a coherent mural backbone competes in favor of Pericyte/mural

## Theca boundary

Theca still requires both a steroidogenic core (`CYP17A1, CYP11A1, STAR, HSD3B1/HSD3B`) and independent androgenic/support evidence (`INSL3, ANPEP, NR5A1, FDX1, FDXR, POR, CYB5A`). `LHCGR` and `DHCR24` are supporting signals, not identity cores.

The contract now binds `observation_unit` into the scorer. In a true cell/nucleus, complete Endothelial, Pericyte/mural or Smooth-muscle programs can be hard competitors to Theca. In cellbin/spot data, sparse adjacent vascular RNA cannot hard-veto a complete Theca program; the vascular candidates remain independent pairwise competitors, with local splitting or unresolved membership used for genuine mixtures.

## Mixed-subcluster behavior

- Endothelial, Pericyte/mural and Smooth muscle enter the complete candidate competition independently.
- A second-round subcluster containing separable direct identity components triggers one bounded local split.
- Candidate subsets are generated independently and overlaps are resolved by direct identity, candidate-local DEG/pseudobulk, pairwise discriminators and spatial components.
- Candidate order cannot decide membership.
- An observation carrying inseparable complete identity cores remains `unresolved_biological`; it is not collapsed into a generic vascular label.

## Follicle ROI audit

The sheep-ovary biological-quality validator now audits separate, optional layers:

1. granulosa boundary;
2. steroidogenic Theca;
3. Endothelial branches interleaved with the theca interna region;
4. Pericyte/mural cells adjoining or wrapping endothelial branches;
5. optional nonvascular mature Smooth muscle;
6. outer Stromal/mesenchymal background.

These are not required to form perfect concentric rings. An absent complete molecular program is negative/not-evaluable rather than an automatic failure. Iteration is required only when a coherent direct multi-family program is materially assigned elsewhere, a published label lacks its core program, or the published spatial morphology is implausible. Geometry can challenge a label but cannot write one.

## Atlas and migration

Explicit endothelial reference labels challenge `Endothelial`; pericyte/mural/perivascular labels challenge `Pericyte/mural`; vascular smooth muscle is re-evaluated against mural and mature smooth-muscle cores. A low-resolution reference `Vascular-associated` has no direct transfer target.

The non-destructive migration preserves old labels as provenance. Old generic vascular membership is cleared from formal broad/fine fields, marked `unresolved_biological`, and exposed publicly as `QC/Unknown` until current-query evidence re-adjudicates its exact source subcluster. Even an old fine label is not accepted without a current-query validated exact-cell patch.

## Remaining limitation

This implementation proves taxonomy and runtime consistency, not biological performance on a new query. A real-sample targeted migration/review is still required before replacing an already approved annotation. Existing valid SCT+BANKSY preprocessing and deterministic second-round partitions should be reused; only source subclusters that contain legacy vascular membership or current molecular conflicts need re-adjudication.
